**Shot:** Open reference spec in Claude Design (of paste prompt preview)

**Voice (bij elke sectie):**
1. **Hero** — full-bleed video loop, "Beyond earth" + "Nft collection" cursive accent, navbar liquid-glass, social icons

4. **CTA / Final** — derde video, "Go beyond" cursive, "JOIN US. REVEAL WHAT'S HIDDEN. DEFINE WHAT'S NEXT. FOLLOW THE SIGNAL."

**Voice:**
- "Vier blokken. Eén storyline: earth → orbis → collection → join."
